# 🚀 EduEarn - Features & Modules

# Product Overview

EduEarn is an AI-powered Learn → Teach → Earn platform where:

• Anyone can learn.

• Students and young professionals (16–24) can become AI-verified tutors.

• Tutors can teach and earn.

The platform consists of three major portals:

1. Public Website

2. Student Portal

3. Tutor Portal

4. Admin Portal

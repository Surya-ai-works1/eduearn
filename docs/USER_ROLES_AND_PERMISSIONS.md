# 👥 EduEarn - User Roles & Permissions

# Overview

EduEarn follows a Role-Based Access Control (RBAC) architecture.

Every user belongs to one of the following roles:

* Guest
* Learner
* Tutor
* Admin
* Super Admin (Future)

Each role has different permissions.

---

# 1. Guest

A guest is a visitor who has not created an account.

Permissions

* View homepage
* Browse courses
* Browse categories
* Search courses
* Search tutors
* Read blogs
* Read FAQs
* View pricing
* Contact support
* View tutor profiles
* Preview course details

Restrictions

Cannot enroll

Cannot purchase

Cannot access dashboards

Cannot create courses

---

# 2. Learner

Anyone can become a learner.

Examples

Kids

Students

Parents

Housewives

Working Professionals

Senior Citizens

Entrepreneurs

Freelancers

There is no age restriction.

Permissions

* Register
* Login
* Edit profile
* Purchase courses
* Join live classes
* Watch videos
* Download certificates
* Complete quizzes
* Submit assignments
* Wishlist courses
* Follow tutors
* Leave ratings
* Leave reviews
* Chat with tutors
* Receive AI recommendations
* Use AI Study Assistant
* Receive notifications

Restrictions

Cannot create courses

Cannot conduct live classes

Cannot earn

---

# 3. Tutor

Initial Eligibility

Students and young professionals aged 16–24.

Requirements

Complete Profile

AI Tutor Assessment

AI Verification

Identity Verification (if required)

Approval

Permissions

Create courses

Edit courses

Upload lessons

Conduct live classes

Create quizzes

Create assignments

Upload resources

View analytics

Manage students

Reply to messages

Receive payments

Withdraw earnings

Manage profile

Receive tutor badge

Restrictions

Cannot access admin features

Cannot approve other tutors

Cannot modify platform settings

---

🎨 EduEarn UI/UX Guidelines
Design Philosophy

EduEarn should feel like a premium global AI-powered EdTech platform.

The experience should be:

Modern
Premium
Minimal
Elegant
Fast
Friendly
Professional
Trustworthy

The UI should combine the best ideas from:

Stripe
Linear
Apple
Framer
Notion
Coursera

Do NOT copy Udemy or Edureka.

EduEarn must establish its own identity.

First Impression

Within the first 5 seconds, users should understand:

What EduEarn is
What they can do
Why they should trust it

The homepage must immediately communicate:

Learn. Teach. Earn.

Design Principles

Every screen must follow:

Large whitespace
Clean typography
Soft shadows
Rounded corners
Smooth animations
Minimal clutter
High readability

Never overload the user.
